# Установка ProxysVPN на macOS

Windows и Linux — в [README_RU.md](README_RU.md#скачать-и-установить).

## Системные требования

- macOS 12 (Monterey) или новее
- Apple Silicon (M1/M2/M3/M4) — поддерживается
- Intel Mac — не поддерживается

## Шаг 1. Установка

1. Скачайте `ProxysVPN_<версия>_aarch64.dmg` со [страницы релизов](https://github.com/evilork/proxysvpn-desktop/releases)
   и сверьте сумму: `shasum -a 256 ~/Downloads/ProxysVPN_*.dmg` — она должна
   совпасть со строкой в `SHA256SUMS.txt` того же релиза.
2. Откройте `.dmg`.
3. Перетащите `ProxysVPN` на ярлык `Applications` в том же окне.
4. Закройте окно и извлеките диск `ProxysVPN` (правый клик на иконке диска → «Извлечь»).
   Запускать приложение прямо из образа не нужно.

## Шаг 2. Первый запуск

Начиная с версии 0.3.7 образ подписан сертификатом Apple Developer ID компании
Watafast LLC и проверен Apple (нотаризован). Команда в Терминале больше не
нужна.

1. Запустите ProxysVPN из `Applications`. macOS один раз спросит, открыть ли
   приложение, загруженное из интернета, — нажмите **«Открыть»**.
2. Введите пароль администратора. ProxysVPN спрашивает его при каждом запуске:
   без него нельзя создать туннель и маршруты. Это отдельное окно самого
   приложения («ProxysVPN запрашивает права администратора…»), не окно
   Gatekeeper.

### Версии 0.3.6 и старше

Их образы подписаны только локально, без Apple Developer ID, и macOS не
запускает их без явного разрешения. Выберите **один** из вариантов.

**Вариант A. Через Терминал (быстрый).** Откройте Терминал (Cmd + Пробел →
«Терминал») и выполните:

```bash
xattr -dr com.apple.quarantine /Applications/ProxysVPN.app
```

После этого ProxysVPN запускается обычным двойным кликом.

**Вариант B. Через настройки (без Терминала).**

1. Запустите ProxysVPN из `Applications`. macOS скажет, что не может проверить
   приложение, — нажмите **«Готово»**.
2. Откройте Системные настройки → **Конфиденциальность и безопасность**,
   пролистайте вниз и нажмите **«Всё равно открыть»** напротив ProxysVPN.
3. Подтвердите паролем или Touch ID.

С macOS 15 «правый клик → Открыть» больше не обходит эту проверку — работает
только путь через настройки или вариант A.

## Что делать если…

**«Приложение повреждено и не может быть открыто»**
Так macOS отвечает на образ версии 0.3.6 и старше: поставьте свежую версию или
снимите карантин (вариант A выше). Если это сообщение показала версия 0.3.7 или
новее — скачайте образ заново и сверьте SHA-256.

**Не запрашивает пароль администратора / ничего не происходит после пароля**
Закройте ProxysVPN полностью (трей → «Выйти») и запустите снова. Если путь к
приложению необычный, переместите его в `/Applications`.

**Окно «Приложение не подготовило свои файлы»**
При запуске ProxysVPN копирует свои движки в защищённую папку
`/Library/Application Support/ProxysVPN/engines`, и это не удалось. Чаще всего
кончилось место на диске: освободите место, закройте ProxysVPN (трей → «Выйти»)
и откройте снова. Причина записана в журнале (`~/Library/Logs/ProxysVPN/app.log`).

**После сбоя или «Завершить принудительно» нет интернета**
Откройте ProxysVPN ещё раз: при запуске он останавливает оставшиеся движки и
убирает свои маршруты. Помогает и перезагрузка.

## Удаление

1. Закройте ProxysVPN (трей → «Выйти») и перенесите его из `Applications` в Корзину.
2. Удалите данные приложения:

```bash
sudo rm -rf "/Library/Application Support/ProxysVPN"
rm -rf ~/Library/Application\ Support/com.proxysvpn.desktop ~/Library/Logs/ProxysVPN
sudo rm -f /tmp/proxysvpn-desktop.pid /tmp/proxysvpn-route-hint /tmp/proxysvpn-hy2.yaml
```

В `/Library/Application Support/ProxysVPN` лежат ссылка подписки (в ней токен
аккаунта), идентификатор устройства, настройки и копии движков.

## Безопасность

Начиная с версии 0.3.7 ProxysVPN подписан сертификатом **Apple Developer ID**
компании Watafast LLC и нотаризован. Это значит:
- подпись подтверждает целостность файлов и то, кто разработчик;
- автоматическая служба Apple проверила эту сборку на известное вредоносное ПО;
- macOS сверяет всё это сама при первом запуске.

Проверить можно и вручную:

```bash
spctl -a -vv /Applications/ProxysVPN.app
```

В ответе должны быть `accepted`, `source=Notarized Developer ID` и строка,
которая начинается с `origin=Developer ID Application: Watafast LLC`.

Версии 0.3.6 и старше подписаны **локально** (ad-hoc подпись): она подтверждает
только целостность файлов после сборки, но не разработчика.

Сверять SHA-256 скачанного образа с `SHA256SUMS.txt` на странице релиза
(шаг 1) стоит в любом случае.

Приложение работает от root. Движки оно запускает из копии в папке root, но
сам исполняемый файл приложения и его лаунчер запускаются от root прямо из
`/Applications/ProxysVPN.app`, а эта папка после перетаскивания принадлежит
вашей учётной записи: программа, работающая под вашим пользователем, может их
подменить, и подмена получит root при следующем вводе пароля. Не запускайте
программы, которым не доверяете. Установщик `.pkg` с привилегированным
помощником, который это закроет, запланирован.
